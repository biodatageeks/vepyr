    RefSeq Cache Source Mode Implementation Plan¶

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Adopt datafusion-bio-functions PR #162 at rev 10d7b4f, make vepyr build caches with explicit source metadata, and stop selecting Ensembl/merged/RefSeq mode through annotation options.

    Architecture: Source mode becomes a build-time cache property. vepyr.build_cache() maps public cache types (vepyr, merged, refseq, deprecated vep) to upstream metadata values (ensembl, merged, refseq) and passes that value to the native cache builder. vepyr.annotate() no longer emits merged or refseq in options_json; upstream annotate_vep() and annotate_to_vcf() read bio.vep.cache_source_type from parquet metadata.

    Tech Stack: Python wrapper in src/vepyr/__init__.py, PyO3 Rust bridge in src/lib.rs, datafusion-bio-function-vep rev 10d7b4f, datafusion-bio-format-ensembl-cache::CacheSourceType, pytest, cargo.

    Current Upstream Facts¶

    • Upstream PR: https://github.com/biodatageeks/datafusion-bio-functions/pull/162
    • Current PR head: 10d7b4f1d313947347cac82596431133da1930f4
    • GitHub CI for that head is green.
    • datafusion-bio-function-vep now resolves datafusion-bio-format-ensembl-cache to rev c3f611769b05b007e315eed310fcab2c47b636cb.
    • Upstream rejects options_json keys merged and refseq, including false values.
    • Upstream requires parquet schema metadata key bio.vep.cache_source_type.
    • Allowed metadata values are exactly ensembl, merged, and refseq.
    • The earlier P1 risk is fixed upstream: zero-copy parquet row-group merge preserves Arrow key/value metadata and has a regression test.

    Compatibility Decision¶

    Use cache_type="vepyr" as the new public default and map it to upstream metadata value ensembl.

    Keep cache_type="vep" as a deprecated alias for one release:

    cache_type="vepyr" -> output directory suffix "_vepyr", metadata "ensembl"
cache_type="vep"   -> output directory suffix "_vep", metadata "ensembl", DeprecationWarning
cache_type="merged" -> output directory suffix "_merged", metadata "merged"
cache_type="refseq" -> output directory suffix "_refseq", metadata "refseq"

    This separates the vepyr API/profile name from upstream's metadata vocabulary, which must remain one of ensembl, merged, or refseq.

    • Step 1: Create a reusable fixture-copy helper

    Create tests/cache_metadata.py:

    from __future__ import annotations

from pathlib import Path
import shutil

import pyarrow as pa
import pyarrow.parquet as pq


CACHE_SOURCE_METADATA_KEY = b"bio.vep.cache_source_type"


def copy_cache_with_source_metadata(
    source_dir: Path,
    target_dir: Path,
    source_type: str,
) -> Path:
    target_dir.mkdir(parents=True, exist_ok=True)
    for source_path in source_dir.rglob("*"):
        relative = source_path.relative_to(source_dir)
        target_path = target_dir / relative
        if source_path.is_dir():
            target_path.mkdir(parents=True, exist_ok=True)
        elif source_path.suffix == ".parquet":
            _rewrite_parquet_with_metadata(source_path, target_path, source_type)
        else:
            target_path.parent.mkdir(parents=True, exist_ok=True)
            shutil.copy2(source_path, target_path)
    return target_dir


def _rewrite_parquet_with_metadata(
    source_path: Path,
    target_path: Path,
    source_type: str,
) -> None:
    table = pq.read_table(source_path)
    existing = dict(table.schema.metadata or {})
    existing[CACHE_SOURCE_METADATA_KEY] = source_type.encode()
    schema = table.schema.with_metadata(existing)
    table = pa.Table.from_arrays(table.columns, schema=schema)
    target_path.parent.mkdir(parents=True, exist_ok=True)
    pq.write_table(table, target_path)

    Commit Boundary¶

    Recommended commits:

    1. chore: adopt bio-functions cache source metadata rev
    2. feat: pass cache source type to native cache builder
    3. feat: map vepyr cache types to source metadata
    4. fix: remove annotate-time source selectors
    5. test: add cache source metadata to golden fixtures
    6. docs: document cache source metadata modes

    Known Non-Goals¶

    • Do not infer source mode from directory names during annotation.
    • Do not add cache_source_type to annotation options_json.
    • Do not mutate checked-in parquet fixture binaries unless explicitly requested.
    • Do not add a new upstream metadata value named vepyr; upstream accepts only ensembl, merged, and refseq.
